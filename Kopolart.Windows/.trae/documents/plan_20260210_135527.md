
# Migration Plan: Windows Forms to Tauri

## 1. Project Analysis & Architecture
The existing application is a "Hybrid" Windows Forms wrapper around `https://kopolart.ir/` with native enhancements.
- **Core Functionality**: Displays remote web content in WebView2.
- **Native Features**: Custom Loading Screen, Offline Error Page, Custom Exit Dialog (with persistence), Desktop Shortcut, Window State Preservation.
- **Target Architecture**: Tauri Application.
    - **Frontend**: Multi-page Web App (Vanilla/React).
        - `index.html`: (Remote) The main application (`kopolart.ir`).
        - `splash.html`: Local loading screen.
        - `offline.html`: Local error handling page.
        - `exit.html`: Custom modal for exit confirmation.
    - **Backend (Rust)**: Handles window management, file/store persistence, and system events.

## 2. Technology Stack
- **Framework**: Tauri 2.0 (using .NET 9 equivalent modern features).
- **Frontend**: HTML5, CSS3, JavaScript (Vite).
- **State Management**: `tauri-plugin-store` (for User Preferences).
- **Window Management**: `tauri-plugin-window-state`.

## 3. Implementation Steps

### Phase 1: Environment & Setup
1.  Initialize new Tauri project: `Kopolart.Tauri`.
2.  Install dependencies: `tauri-plugin-store`, `tauri-plugin-window-state`.
3.  Configure `tauri.conf.json`:
    - Define windows: `main`, `splash`, `exit`.
    - Configure Permissions & CSP to allow `https://kopolart.ir`.
    - Configure Bundle settings (Icons, Identifier).

### Phase 2: Frontend "Shell" Implementation
1.  **Splash Screen (`splash.html`)**:
    - Recreate the logo and background (`#e8d3bc`) from `Form1.cs`.
2.  **Offline Page (`offline.html`)**:
    - Port the HTML/CSS from `OfflineHtmlGenerator.cs`.
    - Implement "Retry" logic using Tauri Event system.
3.  **Exit Dialog (`exit.html`)**:
    - Port the UI from `ExitDialog.cs` (Yes/No buttons, "Don't ask again" checkbox).
    - Implement logic to save preference via `Store` plugin.

### Phase 3: Backend Logic (Rust)
1.  **Main Entry (`main.rs`)**:
    - Initialize plugins (`Store`, `WindowState`).
    - Implement Splashscreen logic (close splash when main loads).
    - Implement Navigation Handler:
        - Intercept navigation errors -> Redirect to `offline.html`.
        - Block external domains -> Open in system browser.
2.  **IPC Commands**:
    - `close_app()`: Terminate application.
    - `get_preference(key)`: Read settings.
    - `set_preference(key, value)`: Save settings.
    - `retry_connection()`: Reload main window.

### Phase 4: Build & Configuration
1.  Generate Icons (convert `.ico`/`.png`).
2.  Configure Release Build (Minification, obfuscation).
3.  Documentation of Build Process.
